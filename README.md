# flow-run

A one-line redirect page. Its only job is to hand off to the `flow://run`
URL protocol handler registered on my Windows machine, which runs a local
Notion sync script.

Clicking the published page does nothing at all unless that handler is
registered locally. It contains no credentials, no endpoints and no personal
data — it is a redirect and nothing else.

Published at the GitHub Pages URL for this repo, and linked from a Notion
page as a "run sync" button.
